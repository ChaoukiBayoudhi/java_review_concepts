# Java review concepts

Review of class, object, redefinition, use of Lombok, inheritance, Comparable interface and collections.

## Tech stack

- Java
- Lombok

## Concepts covered

Comparator/Comparable, collections, console input (Scanner), custom exceptions, exception handling.

## Project structure

- `src`: Student

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Student` (it contains the `main` method).

The code uses Lombok annotations: add the Lombok library and enable annotation processing in your IDE.
